# 中文摘要
本研究旨在建立一套可將企劃內容自動整理為論文格式的系統，以降低排版與整理成本。
研究重點包括章節重組、表圖編號，以及目次、表次、圖次的自動生成。
關鍵詞：生成式AI、論文排版、自動化、文件生成

# 英文摘要
This study aims to build a system that transforms project proposals into thesis-ready documents.
The system focuses on chapter restructuring, figure and table numbering, and automatic generation of the table of contents, list of tables, and list of figures.
Keywords: generative AI, thesis formatting, automation, document generation
