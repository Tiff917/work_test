# work_test

這個倉庫目前包含一套可直接在本機瀏覽器開啟的「專業文件格式生成器」。

它可以把企劃、報告、論文草稿或商業提案內容，整理成正式的 Word 文件，並支援模板切換。

## 目前支援的模板

- 論文版
- 專題報告版
- 商業提案版

## 主要檔案

- `app.py`：本機網頁伺服器與 API
- `paper_generator.py`：Word 文件生成核心
- `web/index.html`：網頁介面
- `web/styles.css`：介面樣式
- `web/app.js`：前端互動與模板切換
- `啟動專業文件格式生成器.bat`：快速啟動

## 使用方式

1. 執行：

```powershell
python app.py
```

2. 或直接雙擊：

- `啟動專業文件格式生成器.bat`

3. 瀏覽器會自動打開本機頁面。
4. 選擇模板。
5. 貼上整篇內容。
6. 按 `生成 Word 文件`。
7. 產出後可直接下載 `.docx`。

## 功能

- 單一大輸入框，整篇內容直接貼上
- 網頁版介面，較適合展示與重複使用
- 支援 `txt`、`md`、`docx` 內容整理邏輯
- 自動整理封面、摘要、目錄
- 論文版與報告版支援表次、圖次
- 自動章節整理
- 自動頁碼
- 支援表格與圖片編號
- 支援參考文獻與附錄

## 可選圖表格式

如果你要在原文中指定圖片或表格，可加入這種標記：

```text
[FIGURE title="流程圖" path="C:/圖片/flow.png" width_cm="13"]
註：圖片說明
[/FIGURE]

[TABLE title="研究規劃"]
| 階段 | 內容 |
| --- | --- |
| 第一階段 | 需求分析 |
註：表格說明
[/TABLE]
```

## 注意

- 第一次用 Word 打開時，如果跳出更新目錄或圖表清單提示，按更新即可。
- 如果原文完全沒有章節格式，系統會先自動包成基本正式文件結構。
- 商業提案版預設會用 `執行摘要` 與 `提案目錄`，更接近提案文件風格。
