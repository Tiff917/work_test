# 專業文件格式生成器

這個工具可以把你整理好的企劃、報告、論文草稿或其他長文內容，直接輸出成正式、乾淨的 `.docx` Word 文件。

## 功能

- 單一大輸入框，整篇內容直接貼上
- 支援開啟 `.txt`、`.md`、`.docx`
- 自動整理封面、摘要、目次、表次、圖次
- 自動整理章節結構
- 自動插入頁碼
- 支援表格與圖片編號
- 支援參考文獻與附錄

## 使用方式

1. 執行：

```powershell
python app.py
```

或直接雙擊：

- `啟動專業文件格式生成器.bat`

2. 直接把整篇內容貼進畫面。
3. 如果原文裡本來就有 `第一章`、`第一節`、`摘要`、`參考文獻`，系統會盡量自動辨識。
4. 按 `生成 Word 文件`。
5. 產出檔案會是 `.docx`。

## 可選圖表格式

如果要指定圖片或表格，可在內容裡加這些區塊：

```text
[FIGURE title="流程圖" path="C:/圖片/flow.png" width_cm="13"]
註：圖片說明
[/FIGURE]

[TABLE title="研究規劃"]
| 階段 | 內容 |
| --- | --- |
| 第一階段 | 需求分析 |
註：表格說明
[/TABLE]
```

## 注意

- 第一次用 Word 打開時，如果跳出更新目錄或圖表清單提示，按更新即可。
- 如果原文完全沒有章節格式，系統會先自動包成基本正式文件結構。
- 輸出格式目前偏向正式學術/報告風格，之後可以再加商業提案、公文、研究報告等不同模板。
