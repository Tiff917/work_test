# work_test

這個倉庫目前包含一套可重複使用的「專業文件格式生成器」，可以把企劃、報告、論文草稿或其他長文內容整理成正式的 Word 文件。

## 專業文件格式生成器

主要檔案：

- `app.py`
- `paper_generator.py`
- `啟動專業文件格式生成器.bat`

功能：

- 單一大輸入框，整篇內容直接貼上
- 支援開啟 `.txt`、`.md`、`.docx`
- 自動整理封面、摘要、目次、表次、圖次
- 自動整理章節結構
- 自動插入頁碼
- 支援表格與圖片編號
- 支援參考文獻與附錄

使用方式：

1. 執行 `python app.py`
2. 或直接雙擊 `啟動專業文件格式生成器.bat`
3. 直接把整篇內容貼進畫面
4. 按 `生成 Word 文件`

可選圖表格式：

```text
[FIGURE title="流程圖" path="C:/圖片/flow.png" width_cm="13"]
註：圖片說明
[/FIGURE]

[TABLE title="研究規劃"]
| 階段 | 內容 |
| --- | --- |
| 第一階段 | 需求分析 |
註：表格說明
[/TABLE]
```

注意：

- 第一次用 Word 打開時，如果跳出更新目錄或圖表清單提示，按更新即可。
- 如果原文完全沒有章節格式，系統會先自動包成基本正式文件結構。
